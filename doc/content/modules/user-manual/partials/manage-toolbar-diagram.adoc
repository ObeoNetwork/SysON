== Toolbar

The Diagram panel has global actions grouped in a horizontal tool bar underneath the diagram tabs.

image::manage-toolbar-main.png[Main Tool bar]

This tool bar contains the following actions:

* Display full screen,
* Fit selection to screen,
* Zoom group (Zoom In, Zoom Out),
* Share the diagram link,
* Export diagram as SVG,
* Toggle snap to grid,
* Show helper line to align elements, 
* Arrange all elements,
* Reveal hidden elements,
* Reveal faded elements,
* Unpin all elements.
